# 溯源论文解读（2025–2026 陕晋宁青 / 陕晋青宁卷）

## 这是什么

本目录收录与本仓库对照表对应的**论文解读**：论文书目信息、摘要中文翻译、关键结果与实验设计、面向高中教学的要点。

**有意不含**高考试题原文、题干、选项、标准答案、解析、题目图片、论文全文 PDF，以及任何指向本地磁盘的路径或下载渠道信息。文件名中的 Q 编号仅用于与本仓库 `高考生物真题×顶刊论文对照表` 交叉定位，不代表题目内容。

## 范围与立场

- 仅收录 2025、2026 两个年度；与对照表一致，**不推导跨年趋势**。
- 星级与确证判定以对照表为准，本目录**不重判溯源**。
- 不推测、不编造 DOI；每篇只给出论文标题与 DOI，可用 `https://doi.org/<DOI>` 合法获取原文。
